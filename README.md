# 🛒 Django Shop 

Учебный проект интернет-магазина, реализованный в рамках курса «Python и фреймворк Django». 
Проект покрывает темы: **хранение файлов, транзакции и кастомизация админки**.

## 📋 Реализованный функционал (по ТЗ)

- **[1] Кастомная функция сохранения изображений:**
  - Автоматическое изменение размера (до 1920px по длинной стороне).
  - Генерация и сохранение превью (300x300).
- **[2] Поддержка нескольких изображений:** Реализована через связь `ForeignKey` (модель `ProductImage`) и `TabularInline` в админке.
- **[3] Замена и удаление файлов:** Настроены сигналы (`pre_save`, `post_delete`) для очистки хранилища от старых файлов при обновлении или удалении товара.
- **[4] Подготовка к облачному хранению:** Настроен `STORAGES` (Django 5) с поддержкой S3 (через `django-storages`). Параметры вынесены в переменные окружения (`.env`).
- **[5] Атомарное оформление заказа:** Функция `checkout` в `services.py` оборачивает создание заказа и списание остатков в `transaction.atomic()`.
- **[6] Защита от гонок данных:** Используется `select_for_update()` для блокировки строк товаров на время оформления заказа (с сортировкой по `id` для предотвращения deadlock).
- **[7] Кастомизация админки:** 
  - Создан отдельный `AdminSite` (`/shop-admin/`).
  - Изменены заголовки, добавлен кастомный CSS (через шаблон `base_site.html`).
- **[8] Inline-модели:** Позиции заказа редактируются внутри заказа (`OrderItemInline`). Реализован подсчет общей суммы заказа.
- **[9] Кастомные фильтры и действия:** 
  - Фильтры по остаткам, статусу и сумме заказа.
  - Массовая активация/деактивация товаров.
- **[10] Действия в админке:** Массовая смена статуса заказа и логирование изменений (в консоль и файл `admin_actions.log`).

## 🛠️ Стек технологий

- **Python** 3.10+
- **Django** 5.0+
- **Pillow** (для обработки изображений)
- **django-storages[s3]** + **boto3** (для облачного хранилища)
- **python-dotenv** (для переменных окружения)
- **SQLite** (база данных по умолчанию)
